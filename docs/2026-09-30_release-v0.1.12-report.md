## 行为变化

- Session → CPA / sub2api、CPA ↔ sub2api 的 Codex 账户按「显式非空字符串 → ID JWT → access JWT → free」解析套餐，去除首尾空白，保留未知套餐名称和原始令牌。其他提供商不自动补充套餐。
- 模型目录使用上游 `codex_cli_rs/0.155.0` 身份，不发送 `Version`。Responses 保留 `codex-tui/0.154.0` 身份与本客户端版本头，并增加实际选中模型的 `X-Codex-Routing-Hint`，不请求 service tier。
- CPA 四个相关文件的审计 blob 更新到 `a270e7b9`；sub2api 两个相关文件内容未变，提交记录为 `42bc7f6c`。
